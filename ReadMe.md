## Do pubescent female birds have reduced heat tolerance?
### This repository contains data and code for this manuscript describing the unexpected mortality due to acute heat stress in Zebra Finches. 

## Organization
### Folder: ExpOutcome_BloodBiomarker_Analyses
This folder contains the data, code, and results for: 
- The secondary analysis of the significance of the deaths by age category and sex was performed using Firth's logistic regression that accounts for the small sample size and complete separation of Sex groups in the observed data.
- The candidate blood biomarkers from blood samples taken 2 weeks prior to the acute heat challenge. 

See the readme in the subfolder for more details.

### Folder: RNAseq_Analyses
#### Bioinformatics subfolder.
This folder contains the code to reproduce the bioinformatic processing of the baseline blood RNAseq data. The raw data and reference genome can be downloaded from NCBI.

See the readme in the subfolder for more details.

#### Statistics
This folder contains the data, code, and results running the differential gene expression analysis and making the corresponding figures.

See the readme in the subfolder for more details.
